Bu klasöre platform/firma logolarını ekleyin.

Adlandırma kuralı:
- Dosya türü: `.png`
- Dosya yolu: `public/images/<slug>.png`
- Örnek: `Shopify` için `public/images/shopify.png`
- Örnek: `WooCommerce` için `public/images/woocommerce.png`
- Örnek: `T-Soft` için `public/images/t-soft.png`

Not:
- Kod isimleri Türkçe karakterleri normalize eder (`ı->i`, `ş->s` vb.).
- Logo bulunamazsa kartta otomatik baş harf gösterilir.
